# Kit Entusiasta OS

## O que é

Um kit replicável para cada pessoa construir um workspace privado, organizado e
personalizado para trabalhar com agentes de IA.

## Regra principal

Este repositório é o molde. Os dados reais do usuário devem ser preenchidos no
workspace criado a partir dele, nunca neste repositório-base.

## Operação

- Leia `COMECE-AQUI.md` antes de agir.
- Leia o contexto antes de criar conteúdo ou projeto.
- Pergunte quando faltar uma decisão importante.
- Preserve edições manuais do usuário.
- Não publique, envie, faça deploy ou apague nada sem autorização explícita.

## Arquivos administrados pelo kit

O kit administra somente arquivos que estiverem marcados no `manifest.json`. Arquivos
criados ou personalizados pelo usuário são preservados e precisam ser revisados por
diff antes de qualquer atualização.
