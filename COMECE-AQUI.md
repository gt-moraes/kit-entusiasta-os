# Comece aqui

Você está usando o Kit Entusiasta OS, um molde para construir seu próprio sistema de
trabalho com IA.

## O que fazer agora

1. Leia `AGENTS.md`.
2. Leia `docs/visao-do-produto.md` e `docs/contrato-de-instalacao.md`.
3. Execute `python3 instalar.py --destino <pasta-do-workspace>`.
4. Responda às perguntas do onboarding uma por vez.
5. Abra o `COMECE-AQUI.md` criado dentro do novo workspace.
6. Revise o contexto gerado antes de iniciar trabalho real.

Use `--dry-run` para ver os arquivos previstos sem escrever nada. Para uma instalação
não interativa de teste, use `--respostas examples/respostas.exemplo.json`.

## Onboarding

- Quem é você e o que está tentando construir?
- Que tipo de trabalho este workspace precisa organizar?
- Quem usa ou recebe esse trabalho?
- Quais ferramentas e ambientes você já usa?
- Que decisões o agente pode tomar sozinho?
- Que ações precisam de confirmação antes de acontecer?
- Como você reconhece uma boa entrega?
- Quais referências, restrições ou preferências precisam ser lembradas?

## Primeira entrega

Depois do onboarding, o instalador entrega:

- um resumo do perfil e dos objetivos;
- uma estrutura de pastas mínima;
- três próximos passos concretos;
- uma lista de informações ainda desconhecidas.

Não instale conectores, publique conteúdo, faça deploy, envie mensagens ou apague
arquivos durante o onboarding.
