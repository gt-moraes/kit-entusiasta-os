# Visão do produto

## Nome

Kit Entusiasta OS.

## Prioridade

Criar um sistema replicável para cada pessoa montar o próprio ambiente de trabalho
com IA. O kit organiza contexto, memória, referências, processos, projetos e regras
de operação.

Landing pages, conteúdo, vídeo, advocacia e outros usos são exemplos de aplicação.
Nenhum deles define o produto.

## Para quem é

Para pessoas que querem trabalhar com um agente de IA de forma contínua, com mais
contexto e menos repetição. Pode servir a um profissional autônomo, criador,
pequena empresa, escritório ou projeto pessoal.

## O que o kit entrega

- onboarding para entender a pessoa e o trabalho;
- estrutura de pastas mínima e expansível;
- arquivos de contexto editáveis;
- workflows reutilizáveis;
- templates para projetos e ideias;
- regras de segurança e preservação;
- caminho para módulos opcionais.

## O que o kit não entrega

- a marca, o conteúdo ou os projetos do autor;
- uma identidade visual pronta para todos;
- automações externas habilitadas por padrão;
- promessa de compatibilidade com qualquer agente antes de testes;
- substituição do julgamento do dono do workspace.

## Critério de sucesso do primeiro teste

Uma pessoa que não conhece o workspace original consegue sair de uma pasta vazia
para um workspace pessoal organizado, entendendo o que foi criado e por quê, sem
precisar copiar dados do autor.
