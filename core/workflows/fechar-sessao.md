# Fechar sessão

Ao terminar uma sessão de trabalho:

1. Resuma o que foi feito.
2. Registre decisões que realmente ficaram definidas.
3. Liste pendências e bloqueios.
4. Aponte arquivos alterados.
5. Sugira o próximo passo mais útil.

Não transforme toda conversa em memória. O objetivo é preservar continuidade sem
encher o contexto com ruído.
