# Iniciar sessão

1. Leia `AGENTS.md`.
2. Leia `_contexto/` e o estado atual do workspace.
3. Identifique a prioridade da sessão.
4. Liste o que está claro, o que falta decidir e qual é o próximo passo.
5. Não altere arquivos só para atualizar contexto: faça isso apenas quando houver
   uma mudança real confirmada pelo dono.
