# Novo projeto

Antes de criar uma pasta, descubra:

- nome do projeto;
- resultado esperado;
- público ou pessoas envolvidas;
- prazo e ferramentas;
- restrições;
- critério de pronto.

Depois, crie uma cópia de `_sistema/templates/projetos/COMECE-AQUI.md` em uma nova pasta
dentro de `projetos/`. Não crie uma estrutura grande antes de entender o trabalho.
